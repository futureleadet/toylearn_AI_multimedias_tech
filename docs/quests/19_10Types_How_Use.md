## 프롬프트 유형과 선택 이유
단계별 해결 프롬프트 : 원인을 찾아서 이를 바탕으로 단계별 문제를 해결해야 함

## 작성 위해 추가 필요 요건

- 일단 복잡한 기술 문서를 간단하고 핵심적인 키워드로 뽑아야 함.
- 기능리스트에서도 차별적인 요소를 찾아내야 함
- 이 두 가지를 핵심으로 타켓에 알맞은 시나리오 도출

## 가상 문제 상황

페르소나: 광고 대행사의 크리에이티브 디렉터 (Creative Director)
배경: 당신은 최근 클라이언트로 합류한 'AI 기반 업무 자동화 SaaS' 스타트업의 신규 캠페인 런칭을 총괄하게 되었습니다. 클라이언트로부터 20페이지 분량의 상세한 **기술 명세서(Technical Specification)**와 기능 리스트를 전달받았습니다.
핵심 문제: 주 타겟 고객은 MZ세대 직장인입니다. 하지만 이 제품은 기능이 복잡하고 기술 용어가 많아, 기존의 텍스트 중심 설명 자료가 "너무 지루하고 복잡하다"라는 내부 테스트 피드백을 받았습니다. 제품의 복잡한 기능을 직관적이고 '힙하게' 전달할 새로운 멀티미디어 접근 방식이 절실한 상황입니다.
해결 과제: 클라이언트가 제공한 20페이지 분량의 기술 명세서를 기반으로, 타겟 고객의 관심을 즉각적으로 사로잡을 수 있는 30초 분량의 '인스타그램 릴스' 또는 '틱톡' 숏폼 영상 광고 시나리오 3가지를 구체적으로 도출해야 합니다. (각 시나리오는 핵심 카피, 비주얼 컨셉, 활용할 BGM 아이디어를 포함해야 합니다.)

## 프롬프트 실행 결과

CD님, 반갑습니다. 제공해주신 [기술 명세서](https://docs.google.com/document/d/1MhJmVGAg9IsvRAyEIjYAL1t1QL1smrALMTBCZHPcT3M/edit?usp=sharing)와 [기능 리스트](https://docs.google.com/spreadsheets/d/1qov8j75c64FJ_bUvDdf2iVHrIbECOT64mNhNNHUnmeY/edit?gid=1024254287#gid=1024254287) (Project 'QuantumLeap') 분석 완료했습니다.

역시나 클라이언트가 제품에 너무 깊이 빠져있네요. 'Cognitive Engine (CE-v3)', 'Kubernetes 기반 마이크로서비스'… 이런 용어는 MZ 직장인에게 'SaaS'가 아니라 'Pass'의 대상입니다.

핵심 문제는 명확합니다. 이들은 '기술'을 팔려 하지만, MZ 직장인은 '저녁이 있는 삶'을 사고 싶어 합니다. 우리의 역할은 이 복잡한 기술을 그들의 '칼퇴'와 '워라밸'로 번역하는 것입니다.

자료 분석 기반의 핵심 전략과 숏폼 시나리오 3가지를 제안합니다.

### 1. 기술 명세서 분석: 핵심 기능 정의 및 키워드 도출

20페이지 분량의 문서를 한 문장으로 요약하면 이렇습니다. **"단순 연결이 아니라, AI가 '대신 읽고, 이해하고, 생각해주는' 자동화."**

* **클라이언트의 언어 (Jargon):**
    * `Cognitive Engine (CE-v3)`
    * `NLP 기반 텍스트 요약 및 감정 분석`
    * `OCR 기반 데이터 추출`
    * `No-Code Workflow Builder`
* **MZ세대의 언어 (Keywords):**
    * **#AI조수** (단순 자동화가 아닌, '조수'라는 인격 부여)
    * **#일잘러치트키** (내가 똑똑해지는 게 아니라, 똑똑한 '수단'을 씀)
    * **#칼퇴부스터** (결과 지향적)
    * **#복붙종료** (가장 지루한 업무(Pain Point)를 직접 타격)
    * **#생각하는자동화** (경쟁사와의 차별점)

### 2. 기능 리스트 분석: 경쟁사 대비 차별점

기능 리스트의 'Competitor Comparison' 시트가 핵심입니다.

* **경쟁사 (예: Zapier, Make):** 'Dumb Pipes' (단순 연결 통로)
    * "IF `메일`이 오면 THEN `Slack`으로 알린다."
    * **한계:** AI가 없습니다. 메일이 '광고'인지 '긴급 클레임'인지 구분 못 하고 다 보냅니다. 사용자가 피로해집니다.
* **우리 제품 (Project 'QuantumLeap'):** 'Smart Brain' (지능형 조수)
    * "IF `메일`이 오면, **AI가 '감정 분석'**을 해서, '긴급 클레임'만 `Slack`으로 알리고, '청구서'는 **AI가 'OCR 스캔'**해서 `Google Sheets`에 자동 입력한다."
    * **차별점:** 단순 반복 노동(A→B)이 아닌, '판단'과 '분석'이 필요한 노동(A→AI Brain→B, C, D)을 대신합니다.

### 3. 30초 숏폼 영상 광고 시나리오 (3안)

이 'Smart Brain' 컨셉을 MZ의 언어로 녹여낸 3가지 시나리오입니다.

#### 1안: "AI 신입, 일 시키기" (유머 / 공감)

* **컨셉:** AI를 '일은 미친 듯이 잘하는데 월급은 안 나가는 신입'으로 의인화. 귀찮은 일을 '시키는' 행위에 집중.
* **핵심 카피:** "신입 뽑았음. 야근? 걔가 함."
* **비주얼 컨셉:**
    1.  **(0~5초)** 1인칭 시점. 책상에 쌓인 영수증(PDF, JPG) 50장. "아... 영수증 처리..." (지겨운 한숨)
    2.  **(6~15초)** [스마트폰 화면] 앱을 켜고 '영수증 폴더' 아이콘을 'AI OCR' 블록에 '툭' 드래그 앤 드롭. → 'Google Sheets' 아이콘에 '착' 연결.
    3.  **(16~25초)** [스플릿 스크린] **(좌)** 주인공은 여유롭게 탕비실에서 커피 마심. **(우)** 모니터 화면. Google Sheets에 영수증의 '날짜', '금액', '내용'이 실시간으로 '착착착' 입력됨. (10배속)
    4.  **(26~30초)** 주인공이 카메라를 보며 윙크.
* **BGM 아이디어:** 경쾌하고 장난스러운 재즈 힙합 비트. (예: 'Pink Panther' 테마의 힙한 리믹스 버전)
* **자막/음성:** (음성) "AI 신입, 50장 처리 10초 컷." → (핵심 카피) "일은 AI가, 월급은 내가."

#### 2안: "워크플로우 ASMR" (직관성 / 쾌감)

* **컨셉:** '노코드'의 직관성을 'Oddly Satisfying'(묘하게 만족스러운) ASMR로 극대화. 기술 설명 대신 시각/청각적 쾌감에 집중.
* **핵심 카피:** "코딩 없이. 그냥. 톡. 착. 끝."
* **비주얼 컨셉:**
    1.  **(0~5초)** 미니멀한 3D 그래픽. 'Gmail', 'Slack', 'AI Brain' 아이콘이 떠 있음. "코딩? 1도 모름." 자막.
    2.  **(6~20초)** 세련된 손(MZ세대 스타일 네일)이 나타나 스마트폰 화면에서 아이콘을 끌어옴.
    3.  'Gmail' 아이콘을 '톡' 놓는다. → (자막) "메일 오면"
    4.  'AI Brain' 블록에 '착' 붙인다. → (자막) "AI가 읽고"
    5.  'Slack' 아이콘에 '스윽' 연결한다. → (자막) "알아서 보고"
    6.  완성된 워크플로우(Gmail → AI → Slack)에서 빛의 흐름이 부드럽게 이어짐.
* **BGM 아이디어:** BGM 대신 극대화된 **ASMR 사운드 이펙트(SFX)**.
    * (아이콘 놓을 때) "톡." (부드러운 소리)
    * (블록에 붙일 때) "착." (자석처럼 붙는 소리)
    * (연결될 때) "스르륵-" (빛이 흐르는 소리)
* **자막/음성:** (핵심 카피) "잇다. 생각하다. 끝내다."

#### 3안: "5:59 PM, 칼퇴 치트키" (Before & After 극적 대비)

* **컨셉:** '칼퇴'라는 명확한 베네핏을 빠르고 감각적인 교차 편집으로 극명하게 대비.
* **핵심 카피:** "반복 업무, 아직도 네가 해?"
* **비주얼 컨셉:**
    1.  **(0~10초) [Before - 흑백/차콜톤]** 시계 5:59 PM. 1인칭 시점. 모니터에 "긴급 CS 이메일 120건", "주간 보고서 데이터 취합" 팝업. 마우스 광클, 키보드 연타.
    2.  **(11~15초) [Transition]** 주인공이 "에휴-" 한숨 쉬다 결심한 듯 스마트폰 앱을 '탭'한다. (빠른 줌인 + "띵!" 효과음)
    3.  **(16~25초) [After - 풀컬러/따뜻한 톤]** (BGM 비트 드롭) 3인칭 시점. 텅 빈 사무실. 주인공이 가방 메고 "칼퇴~" 입 모양으로 윙크. / (빠른 컷 전환) 한강 러닝, 친구와 치맥, 집에서 넷플릭스.
    4.  **(26~30초)** (자막/음성) "AI에게 맡기고, 너는 칼퇴해."
* **BGM 아이디어:** (Before) 빠르고 긴장감 넘치는 글리치(Glitch) 사운드 → (Transition) "띵!" → (After) NewJeans 또는 ADOY 풍의 트렌디하고 청량한 K-Indie 비트.
