# 영상 콘텐츠 기획안

## 1. 캠페인 개요

### 1.1 핵심 컨셉

[cite_start]**"숨결이 모여 숲이 될 때"** [cite: 1, 3]
- [cite_start]평범한 시민 개개인의 작은 숨결(관심)이 모여 거대한 숲(변화)을 만들 수 있다는 '연대감'과 '희망'의 메시지 전달 [cite: 1, 3]

### 1.2 크리에이티브 방향

- [cite_start]진정성 있고 따뜻한 톤앤매너 선호 [cite: 1]
- [cite_start]평범한 시민들(직장인, 부모, 노부부 등)의 인터뷰를 기반으로 한 다큐멘터리 형식 [cite: 1, 3]
- '도시 숲이 필요하다'는 정보 전달을 넘어, '나도 한번 참여해볼까?' [cite_start]하는 실질적인 행동 유도 [cite: 1, 3]

---

## 2. 콘텐츠 시리즈 구성

### 시리즈 A: "숨결이 모여 숲이 될 때" (메인 공익광고)

- [cite_start]**포맷:** 30초 TVC (공익광고 PSA) 및 온라인 바이럴 영상 [cite: 1, 2]
- [cite_start]**내용:** 삭막한 도시의 답답함(개인) → 시민들의 작은 숨결(인터뷰) 교차 → 모든 숨결이 모여 푸른 숲을 이루는 감동적 이미지로 전환 [cite: 1, 3]
- [cite_start]**활용:** TV PSA 시간대 집중 노출, 유튜브/SNS 바이럴 확산 [cite: 1]

### 시리즈 B: "도시의 숨, 우리의 숨" (라디오 캠페인)

- [cite_start]**포맷:** 20초 음성 광고 (미디어 후원 연계) [cite: 1]
- [cite_start]**내용:** 메인 영상의 감성적 오디오(시민 목소리, BGM)를 활용하여 출퇴근 시간대 운전자들의 공감대 형성 [cite: 2]
- [cite_start]**활용:** 주요 라디오 채널 출퇴근 시간대 미디어 후원 집행 [cite: 3]

### 시리즈 C: "내 숨을 위한 한 평" (참여형 바이럴)

- **포맷:** 15초 숏폼 (메인 영상 소스 활용)
- [cite_start]**내용:** 메인 영상의 가장 감동적인 시민 인터뷰 클립을 활용, '#내숨을위한한평숲' 해시태그를 통한 메시지 확산 [cite: 2]
- **활용:** 인스타그램 릴스, 유튜브 쇼츠 등 숏폼 플랫폼 배포

### 3.1 프로덕션 일정

- 1주차: 프리 프로덕션 (시민 인터뷰 섭외, 스토리보드 확정)
- [cite_start]2주차: 메인 촬영 (시민 인터뷰, 도시/숲 스케치 촬영) [cite: 3]
